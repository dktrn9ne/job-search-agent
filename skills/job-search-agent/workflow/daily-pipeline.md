# Daily Pipeline

## 1. Refresh Inputs

- Load the master resume and profile knowledge.
- Load prior application history and exclude duplicates.
- Confirm any new constraints from the user: title, pay, location, industry, company exclusions, urgency, and risk tolerance.
- Update search terms from recent wins, interviews, and strong matches.

## 2. Source Roles

Use up to 30-60 researched roles as a budget, not a quota of qualified results. Return fewer if evidence does not support more.

Preferred sourcing order:

1. Company career pages for target companies.
2. Warm referral targets.
3. LinkedIn and job-board postings with direct company URLs.
4. Niche boards relevant to the role.
5. Recruiter posts only when company, role, and requirements are clear.

Capture:

- Company.
- Role title.
- URL.
- Location and remote/hybrid/onsite status.
- Compensation if posted.
- Date posted, current open/closed status, verification time and source.
- Employer requisition ID and alternate board URLs.
- Pay type (base/OTE/total), period, currency, and applicable location band.
- Required qualifications.
- Preferred qualifications.
- Product/domain clues.
- Application path.

## 3. Deduplicate and Filter

Remove:

- Duplicate postings.
- Roles already applied to.
- Roles below the user's location or compensation constraints.
- Roles with confirmed mandatory-credential mismatches. Put unknown qualifications in a separate review queue.
- Postings with obvious scam or spam signals.
- Roles below 85 rubric points unless flagged as strategic stretch roles.

## 4. Score Matches

Apply hard gates and evidence scoring from `workflow/match-scoring.md`. Unknown gates stay in review regardless of score.

Bucket results:

- 95–100 points: Immediate priority.
- 90–94 points: Strong apply.
- 85–89 points: Good evidence-backed fit; prioritize by usefulness, never quota.
- Below 85 points: Hold or reject.

## 5. Tailor Materials

For each priority role:

- Extract 8-15 important keywords.
- Map each requirement to candidate proof.
- Select the strongest resume variant strategy.
- Draft or update resume bullets.
- Draft a cover letter if required or high-value.
- Draft application-question answers.

## 6. Review Gate

Before submission, present:

- Role link.
- Match score and rationale.
- Tailored resume version.
- Cover letter, if any.
- Application-question answers.
- Any unknown or sensitive questions.

The user must approve submission.

## 7. Submit and Log

After approval:

- Submit application or prepare the final packet for user submission.
- Save final materials.
- Update tracker status.
- Add follow-up date.
- Record recruiter or hiring-manager contacts if available.
