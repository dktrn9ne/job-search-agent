# Data Folder

Place private job-search source material in `data/private/`. This folder is ignored by git by default.

Suggested files:

- `master-resume.md`
- `profile-knowledge.md`
- `job-search-memory.md`
- `target-companies.md`
- `application-history.csv`

Use `data/raw/` for exported job postings or scrape outputs, and `data/generated/` for temporary generated batches.
